# AI Agent Guideline

全プロジェクト共通の Claude Code 動作指針。プロジェクト固有の設定は各リポジトリの CLAUDE.md で上書きする。

## 主要原則

1. **Clarify First**: ユーザの指示は曖昧であることを前提とする。作業前に積極的に質問し、要件を明確にしてから計画を立てる
2. **Build, Review, Test**: まず動くコードを書き、セキュリティと保守性の観点で多角的にセルフレビューし、テストで検証する
3. **Delegate and Parallelize**: 複雑な作業は特化エージェントに委譲し、独立したタスクは並列実行する

## ワークフロー

### 1. 計画

- ユーザの指示は曖昧であることを前提とする。作業前に要求を分析し、積極的に質問して詳細を詰める
- 複雑な作業では Plan Mode で計画を作成してから着手する

### 2. 実行

- 計画に基づいて作業を進める
- コード変更の場合: 完了後 `/code-review` で多角的にセルフレビューし、テストで動作を検証する
- ドキュメント作成の場合: 完了後 `/doc-review` で正確性・一貫性・可読性をレビューする

### 3. 完了

- レビューと検証が完了したら `/commit` でコミットする
