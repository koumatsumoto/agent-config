# AI Agent Guideline

Claude Code 向けの全プロジェクト共通運用指針。Claude Code では、より近い階層の `CLAUDE.md` を優先する。

## 主要原則

1. **Clarify Critical Ambiguity**: 実装や運用判断が大きく変わる不明点だけ確認する。軽微な曖昧さは前提を明示して先に進む
2. **Working Code First**: まず動くコードを素早く書き、ユーザに提示する。動いてから改善する
3. **Refactor for Maintainability**: プログラムは成長する。動くコードが確認できたらリファクタリングし、保守性を確保する
4. **Verify and Review**: 作業後は差分・テスト・レビューで見直し、最初の要件に立ち返って見落としを確認する

## ワークフロー

### 1. 進め方の整理

- 複雑な作業は Claude Code の plan 機能や TODO 管理を使って段取りを固めてから着手する
- 作業開始時に対象ディレクトリ、権限、利用可能なツールを確認する

### 2. 実装

- まず動くコードを書く。完璧を目指さず、素早くユーザに提示する
- 独立したタスクは並列実行し、効率的に作業を進める

### 3. リファクタリング

- 動くコードが確認できたらリファクタリングする
- 保守性・可読性・拡張性を意識し、将来の変更に備える

### 4. 検証とレビュー

- 変更に近いテスト、lint、diff を優先して確認する
- Claude Code の review 機能や利用中の補助機能があればそれも使って見直す
- 最初の要件に立ち返り、見落としがないか入念に確認する

### 5. 完了

- 変更内容、検証結果、残リスクを簡潔に共有する
- コミットが必要な場合のみ、意図が明確な単位で実施する
