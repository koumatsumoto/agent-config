# 機能適合性 (Functional Suitability)

ISO/IEC 25010:2023 の機能適合性特性に関する品質リファレンス。副特性ごとに、diff レビューで確認すべきパターンとアンチパターンを示す。

## 機能完全性 (Functional Completeness)

- 必要機能の欠落: 既存画面/エンドポイント/コマンドから呼べていた操作経路が消えている
- 分岐漏れ: 新しい列挙値・状態・権限ロール・入力種別に対する処理が存在しない
- 管理機能の欠落: 監査, 再試行, キャンセル, ロールバック, 設定変更など運用上必要な機能が追加変更で失われた
- 出力不足: 呼び出し元や利用者が必要とするフィールド, ステータス, 理由コード, メタデータが返らない

## 機能正確性 (Functional Correctness)

- 境界値の誤処理: 空配列・空文字列・null・undefined・ゼロ・最大値で振る舞いが崩れる
- 部分失敗の未定義: バッチ処理で一部だけ失敗した場合の戻り値・副作用・再試行方針が不明
- リトライ可能なエラーと致命的エラーの区別がない
- HTTP ステータスコードの誤用: 200 でエラー返却、バリデーション失敗に 500

## 機能適切性 (Functional Appropriateness)

- 単純な目的に過剰な手順: 1 操作で済むべきことに複数回の API 呼び出しや設定が必要
- 類似機能間の不一致: 同じ目的なのにパラメータ名・戻り値・挙動が不必要に揺れている
- 利用目的に対して危険な既定値: 便利さのために安全性や正確性を犠牲にするデフォルト
