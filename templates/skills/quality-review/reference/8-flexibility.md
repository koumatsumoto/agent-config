# 柔軟性 (Flexibility)

ISO/IEC 25010:2023 の柔軟性に関するリファレンス。環境差し替え、スケールアウト、導入 / 更新 / ロールバック、ベンダー置換のしやすさを見る。

## 副特性ごとのアンチパターン + diff シグナル

### 適応性 (Adaptability)

- URL、パス、ポート、資格情報のハードコード
- OS 固有パス区切り文字やローカル前提
- ドキュメント化されていない環境変数や、衝突しやすい汎用名への依存

### スケーラビリティ (Scalability)

- メモリセッション、ローカルキャッシュ、ローカルストレージ前提
- 単一インスタンス前提のロック、プロセス内スケジューラー、インメモリキュー
- プロセス間共有状態をグローバル変数に置く

### 設置性 / 置換性 (Installability / Replaceability)

- 手作業前提の導入、順序依存 migration、暗黙の権限や依存
- one-way migration や後方互換のない設定変更でロールバックできない
- 特定ベンダー SDK や独自形式へ密結合し、差し替え面がない

## surface 条件付き補助観点

- `cloud runtime / IaC`: config を環境から分離できているか、デプロイ / ロールバック前提を壊していないかを見る
- `external integration`: SDK 直結、認証情報管理、差し替え面、バージョン固定を確認する
- `database / data store`: migration のロールバック性、単一 DB 前提の埋め込みを確認する

## false positive 注意

- 意図的なベンダー採用自体を問題にしない。差し替え不可能な密結合かで判断する
- ローカル専用の開発ツールに対して、分散スケールを過剰要求しない
- 環境変数を増やすこと自体を柔軟性向上と見なさない。設定境界が明確かで判断する
