# Intent Review 出力形式

## 構造化出力

```
### 要求リスト
1. [明示的] ...
2. [合意] ...
3. [暗黙的/推測] ...

### 合意された設計判断
- ...
```

## サマリー（必ず冒頭に出力）

```
## レビュー結果

**レビュー種別**: Intent Review
**検出件数**: HIGH: 0 / MEDIUM: 1 / LOW: 0
**コミット判定**: PASSED
```

## 問題報告

```
## MEDIUM: ページネーション機能が未実装 [confirmed]

**要求**: 「一覧表示にページネーションを追加してほしい」（会話履歴より）
**現状**: API エンドポイントは作成されたが、ページネーションパラメータの処理が未実装
**対応**: offset/limit パラメータのハンドリングを追加する
```
