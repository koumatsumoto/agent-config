# Body Writing Principles

issue / PR 本文の構成は固定テンプレートにしない。代わりに次の原則だけを守る。

- 読み手が次の工程へ進めるだけの情報を含める
- 設計判断、制約、スコープ外などの難所を明文化する
- 受け入れ条件は検証可能な表現にする
- 軽微な変更では簡潔に、設計判断が多い変更では詳細に書く
- 同じ内容を重複して長く書かない
- 計画 issue の本文は `km:plan` が管理する。本スキルでは PR 本文と ad-hoc issue 本文だけを対象にする
- PR 作成後は実装成果物の説明を PR 側に寄せ、issue の詳細同期は続けない
- レビュー結果は `km:review` のレポートで扱い、issue 本文に書き写さない
