# GitHub issueへの反映

計画本文の先頭付近に`<!-- km:plan:managed -->`を置き、一時ファイルと同じ本文を`--body-file`で反映する。
既存issueの更新が明示されていなければ新規作成し、計画内容からタイトルを付ける。

更新を明示された既存issueは、次の条件で扱う。

- マーカーがあれば全文を更新してよい
- マーカーがなければ、全文置換の前にユーザーへ確認する
- 内容と合わなくなったタイトルは必要に応じて更新する

作成・更新のどちらも、一時ファイルとissue本文を一致させる。GitHubへ反映できなければ一時ファイルまでで止め、反映できなかったことを報告する。
