# GitHub issueへの反映

計画本文の先頭付近に `<!-- km:plan:managed -->` を入れ、`.plan/` と同じ本文を `--body-file` でGitHub issueへ反映する。

## 新規作成方法

明示がない限り新規issueを作る。タイトルは計画内容から付ける。
GitHubへ反映できない場合は `.plan/` への出力までで止め、issueを作成できなかったことを報告する。

## 既存issueの更新

ユーザーが既存issueの更新を明示した場合だけ更新する。

- `<!-- km:plan:managed -->` があるissueは全文を更新してよい
- マーカーがないissueは、全文置換する前にユーザーへ確認する
- 計画内容と合わなくなった場合は必要に応じてタイトルも更新する

更新時も `.plan/` とissue本文を同じ内容に保つ。
