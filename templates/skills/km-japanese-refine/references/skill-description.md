# Skill description

descriptionはskill選択に使うメタデータであり、本文の要約ではない。

## 必須情報

1. 対象
2. 達成すること
3. 使用する依頼・状況
4. 誤選択が起きる場合だけ、隣接skillとの最小限の境界

## 含めない情報

- 内部手順、ファイル構成、サブエージェント、人数、判定状態
- 実装方式、長い利点、一般的なLLM能力
- 起動判断に使わない背景・例外

## 書き方

- 対象と働きを先に、使用場面を続ける
- 実際の依頼に現れる具体的な語を含める
- 「私」「あなた」を主語にしない
- 強い禁止や責務境界は、誤起動を防ぐ場合だけ加える
- agent-configでは一行のYAMLスカラーで書く。一行の中で二〜三文に分けてよい

## 合否

descriptionだけを読んだAIが、代表的なshould/should-notを正しく分類できること。短さより、ルーティングに必要な意味がそろっていることを優先する。
