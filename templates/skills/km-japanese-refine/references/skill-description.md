# Skill description

descriptionは本文の要約ではなく、skillを選択するためのメタデータ。

対象・達成すること・使用する依頼や状況をこの順で書く。隣接skillとの境界は誤選択を防ぐ場合だけ加える。
実際の依頼に現れる具体語を使い、「私」「あなた」を主語にしない。
agent-configでは一行のYAMLスカラーとし、一行内で二〜三文に分けてよい。

内部手順、ファイル構成、subagent、人数、判定状態、実装方式、長い利点、一般的なLLM能力、選択に使わない背景・例外は書かない。強い禁止も誤起動の防止に必要な場合だけ使う。

descriptionだけで代表的なshould / should-notを分類できることを合否とし、短さより選択に必要な意味を優先する。
