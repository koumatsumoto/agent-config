# security

**反証命題** — この変更は、現実的な攻撃者・濫用者が利用できる経路を新設せず、信頼境界、権限、テナント分離、秘密・機密データ、危険な副作用を保全している。

見るもの:

- 主体、資産、入口、信頼境界
- 認証・認可、所有者、役割、特権、テナント分離の迂回
- 秘密情報・個人情報の入力、保存、ログ、エラー、外部送信
- 未信頼入力からquery、command、template、path、tool、外部送信までの経路
- 削除、送信、課金、本番反映、CI/CD、認証情報利用など高影響の副作用
- 正当な利用者による濫用と監査可能性

現実的な攻撃主体、入口、破られる境界、得られる結果を構成できない一般的な堅牢化は指摘にしない。

指摘には、攻撃・濫用主体、入口、前提、破られる境界、達成される結果を一つのシナリオとして示す。秘密値そのものは複製しない。
