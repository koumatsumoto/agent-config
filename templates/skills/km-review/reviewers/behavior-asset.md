# 挙動資産のレンズ

skill / rule / `CLAUDE.md` のような **agent に読み込まれて挙動を規定する prompt 定義**は、読まれて実行される挙動定義であり、その欠陥は実行時の事故を起こす。対象が挙動資産に分類された実行では、自分の担当レンズを次の意味へ写像して当てる（通常の code diff では当てない）。

- **不変条件** = gate・収束・安全確認の伝播。本経路が通す gate（秘密チェック・承認・収束判定・silent-drop 防止）を、新設・分岐した副経路が機械的に継承しているか。prompt 資産で最頻の欠陥クラス
- **攻撃面** = 公開・書き込み経路。この資産が引き起こす外部公開・永続化（issue への全文ミラー、ファイル書き込み、外部送信、秘密情報の扱い）を egress として棚卸しし、意図しない公開・巻き込みが無いか
- **最悪入力** = 最も安価に指示を満たす実装者。字面どおり最小コストで満たす literal な読み手を想定し、その読み方で安全確認・品質が抜け落ちないか。「善意で丁寧な読者」を前提にしない
- **波及** = 下流 skill との契約。入力形式・marker・前提を暗黙に変えていないか

主担当は、不変条件の継承 = generalist / adversary、公開・書き込み経路 = security、下流契約の波及 = architect。担当外でも見えた懸念は出す。
