# ISO/IEC 25010:2023 品質特性（レビュー観点の早見）

km:review Phase 3 の共通レビュー観点。各レビュアは**担当特性の副特性**を観点として diff に当てる（担当: architect = 2/3/7/8、security = 6/9、adversary = 1/4/5）。**網羅チェックリストではなく、見落としやすい観点を想起するための lens**。該当しない特性は飛ばす。

| # | 特性 | 副特性（観点） |
|---|---|---|
| 1 | 機能適合性 | 完全性・正確性・適切性 |
| 2 | 性能効率性 | 時間効率性・資源効率性・容量充足性 |
| 3 | 互換性 | 共存性・相互運用性 |
| 4 | インタラクション能力 | 適切度認識性・学習性・運用操作性・ユーザエラー防止・UI 美学・アクセシビリティ |
| 5 | 信頼性 | 成熟性・可用性・障害許容性・回復性 |
| 6 | セキュリティ | 機密性・完全性・否認防止・責任追跡性・真正性・耐性 |
| 7 | 保守性 | モジュール性・再利用性・解析性・修正性・試験性 |
| 8 | 柔軟性 | 適応性・スケーラビリティ・設置性・置換性 |
| 9 | 安全性 | 運用制約・リスク識別・フェイルセーフ・ハザード警告・安全な統合 |
