# Code Review

未コミット変更を対象に、多角的・多層的なレビューを行う。

## Workflow

1. `git diff --name-only` で変更ファイルを収集する
2. **仕様突合**: ユーザーの元の要求・仕様を振り返り、変更が要件を満たしているか確認する
3. **多層レビュー**: 関数 → モジュール → システムの順にレビューする
4. **多角レビュー**: セキュリティ・正確性・堅牢性・保守性の4観点でレビューする
5. 問題を重大度順に報告する。`CRITICAL/HIGH` があればコミットをブロックする

## Phase 1: 仕様突合

IMPORTANT: コードの詳細に入る前に、まずユーザーの元の要求を振り返る。

- 要求された機能・修正がすべて実装されているか
- 要求されていない変更が混入していないか
- エッジケースや境界条件が仕様レベルで考慮されているか

## Phase 2: 多層レビュー

### 関数/メソッドレベル

- 入出力の型は正しいか。`null` / `undefined` / `None` の扱いは適切か
- エッジケース（空配列、0、空文字、境界値）でも正しく動作するか
- エラーパスは適切にハンドリングされているか
- 副作用が明確か（引数の変更、グローバル状態の変更）

### モジュール/ファイルレベル

- 1つのファイル/クラスが1つの責務に集中しているか
- 依存の方向は適切か（具象→抽象、外→内）
- 公開インターフェースは最小限か（不要な export / public がないか）
- 変更が他モジュールに予期しない影響を与えないか

### システム/アーキテクチャレベル

- データフロー全体で型安全性が保たれているか
- 信頼境界（外部入力、認証、データ永続化）を跨ぐ箇所は安全か
- 変更の波及範囲を把握できているか
- パフォーマンスへの影響（N+1 クエリ、不要なループ、メモリリーク）はないか

## Phase 3: 多角レビュー

### セキュリティ

信頼境界に触れる変更を優先的に確認する。詳細なチェックリストは security-checklist.md を参照。

- ハードコードされたシークレットがないか
- 認証・認可が適切に実装されているか
- 外部入力が検証なく使用されていないか（SQL, テンプレート, シェル, パス結合）
- 例外の握り潰しによる fail-open がないか
- 機密情報がログ/エラー出力に含まれていないか

### 正確性

- 仕様どおりの動作をするか（Phase 1 の結果を踏まえる）
- 既存機能を壊していないか（仕様回帰）
- データの整合性は保たれるか（型変換、丸め、タイムゾーン）
- 条件分岐に漏れがないか（exhaustiveness）

### 堅牢性

- 例外が適切に伝播しているか（握り潰し、cause チェーンの欠落）
- リソース解放は確実か（ファイル、接続、トランザクション）
- 並行アクセスで整合性が壊れないか（TOCTOU、共有状態）
- 外部サービス障害時の振る舞いは適切か（タイムアウト、リトライ、フォールバック）

### 保守性

- 変数名・関数名が意図を正確に表現しているか
- ネストが深すぎないか（早期 return で簡潔にできないか）
- 同一ロジックのコピペがないか
- 変更箇所に対応するテストが追加・更新されているか

## Mandatory Blockers

以下を検出した場合はコミットをブロックする:

- ハードコードされたシークレット（API キー、パスワード、トークン）
- 認証・認可の欠如
- 非検証入力の直接利用（注入脆弱性）
- 機密情報を含むログ/エラー出力
- セキュリティ関連の例外握り潰し（fail-open）

## Severity Guide

- `CRITICAL`: 機密漏えい、認可欠如、任意コード実行、fail-open など即時悪用可能
- `HIGH`: 明確なバグ、仕様回帰、悪用可能な入力検証不足
- `MEDIUM`: 保守性低下、テスト不足、設計の不整合、不適切なエラー処理
- `LOW`: 微小改善

## Output Format

問題ごとに以下の形式で報告する。

**Example:**

```
## CRITICAL: ハードコードされた API キー

**場所**: src/api/client.ts:42
**問題**: Stripe の API キーが文字列リテラルとして埋め込まれている。リポジトリにアクセスできる全員がキーを取得でき、不正課金に悪用される。
**修正**: 環境変数 `STRIPE_SECRET_KEY` から読み込むように変更する。
```
